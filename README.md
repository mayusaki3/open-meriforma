# Open MeriForma

**読み方：オープン・メリフォルマ**

**オープンでモジュール化された Physical AI ロボットプラットフォーム**

Open MeriForma は、Meridian Project と連携する小型ヒューマノイド／ドール型ロボットのオープンソースハードウェアプロジェクトです。

**MeriForma（メリフォルマ）** は *Meri(dian) + Forma* からなる名称で、Meridian が物理世界で取る「形・身体」という考え方を表しています。

単一の完成したロボットを定義するのではなく、交換可能なモジュールを組み合わせることで、身体を製作・修理・改造・再構成できるプラットフォームを目指します。

---

## プロジェクトの目標

- オープンソースハードウェア
- 3Dプリンターによる製作を主体とする
- 個人でも製作可能な低コスト性
- モジュール化され、修理しやすい身体構造
- アクチュエータ、関節、センサー、外装、手、足等の交換性
- 可能な範囲で実際の関節状態を独立して計測
- 複数の身体構成・移動形態
- 会話、表情、ジェスチャー、移動を含むAIとの身体的インタラクション
- 個体差や経年変化に対する学習・適応
- 保守や部品交換判断を支援するHealthモニタリング
- AI・適応学習から独立したリアルタイム安全保護

---

## モジュール化された身体

Open MeriForma は、身体構成を一種類に固定しません。

例えば以下のようなモジュールを想定します。

- 簡易頭部 / ディスプレイ式頭部 / 機械式表情頭部
- 固定手 / 簡易ハンド / 5指ハンド
- 標準脚 / 高機能脚
- 通常足 / 展開式車輪付き足
- 通常手 / 車輪付き手

高機能構成では、ギア駆動の差動指、肩甲骨に相当する可動肩構造、可動つま先、機械式表情、展開式車輪等を検討します。

また、荷重を受ける関節機構と交換可能な駆動アクチュエータを可能な範囲で分離し、サーボ等を交換しても肢全体を作り直さずに済む構造を重視します。

---

## 複数の移動形態

Open MeriForma の移動能力は、「二足ロボット」等の固定分類ではなく、現在装着されている身体モジュールが提供するCapabilityの組み合わせによって決まります。

例えば以下を想定します。

- 二足歩行
- 手と足を四肢として使用するハイハイ等の四足移動
- 足の展開式車輪を利用する二輪移動
- 車輪付きの手と足を利用する四輪移動
- 歩行と車輪を組み合わせた移動

AIは利用可能なCapability、身体のHealth、周囲環境、安定性、行動目的等から適切な移動方法を選択できることを目指します。

---

## AIと行動

AIは学習だけでなく、以下にも利用します。

- 人間との会話
- 人間や周囲の認識
- 状況に応じた反応
- 表情やジェスチャー、移動の選択
- 現在の身体構成・状態を考慮した行動決定
- 機体特性の学習と適応
- Healthの解釈と人間への提示

上位の「意図」と具体的な関節動作は分離します。

例えば「別れの挨拶として手を振る」という場合でも、特定の腕を必ず使用するのではなく、片腕が故障または劣化していれば状態の良い腕を使用し、必要ならお辞儀や音声等の別の表現を選択できることを目指します。

---

## 学習と適応

学習は以下から選択可能とする方針です。

- 実機
- シミュレーション
- 両者の組み合わせ

シミュレーション環境としてMuJoCoを想定しています。

学習結果は、大規模AIモデルが各関節を常時直接制御する形式ではなく、制御用マイコンで実行可能な形へ変換することを基本とします。

例えば以下です。

- 計算式・制御パラメータ
- モーション
- モーション補正
- センサーフィードバックの期待値
- 想定範囲
- 状態判定・補正ロジック

実際の状態が学習済み想定範囲から頻繁に外れる場合は、その逸脱を人間へ提示します。

人間が現在の状態を許容すると判断した場合は再学習し、新しい状態へ適応できる仕組みを目指します。

これにより、部品の個体差、センサー値の変化、アクチュエータの経年変化、部品交換、構成変更等への適応を可能にします。

---

## Healthと保守

再学習して現在状態へ適応しても、過去の基準状態を失わないようにします。

基準状態、現在の学習状態、過去の学習履歴を保持し、経年変化等を継続して観測できる構造を目指します。

基準状態からのずれを部位ごとに色等で可視化し、「現在動くか」だけでなく「以前と比較してどの程度特性が変化したか」を人間が確認できるようにします。

この情報を点検や部品交換時期の目安として利用します。

Health情報はAIの行動決定にも利用し、劣化した部位を避け、状態の良い部位を優先する等の行動を可能にします。

---

## 安全

即時安全保護は、AIによる行動決定や適応学習とは独立した系統として扱います。

例えば以下です。

- 過電流
- 過熱
- 転倒または転倒危険
- その他、即時の制限・停止を必要とする状態

通常の適応学習によって、これらの安全限界を自動的に拡大することは基本的に認めません。

---

## 基本思想

Open MeriForma は、

**「交換可能な身体」**

と

**「その身体を観測し、学習し、現在の能力と状態を理解して行動するAI」**

を組み合わせます。

部品交換、構成変更、個体差、経年変化を前提とし、それらに適応しながら人間と関わる、修理・改造可能なPhysical AIプラットフォームを目指します。

Open MeriForma は現在、基本構想・要件検討段階です。

基本方針を不必要に制約しないよう、各要素を個別に検討して決定します。
