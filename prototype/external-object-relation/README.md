# External Object Relation Prototype

This prototype validates interaction between a Body Graph and a World Graph without turning external objects into Forma Units.

Initial questions:

- Can Body and World entities keep independent identities and graph membership?
- Can temporary Interaction Relations connect them without changing either graph?
- Can a Capability depend on a relation such as grasp, contact, or support?
- Does removing a relation remove only the temporary capability condition?
- Can one external object participate in more than one relation?

This is concept validation. Relation names, JSON schema, object taxonomy, and capability names are not final standard definitions.
