# Handover

Handover files are optional, derived from ../Worklog/runtime-invalidation-events.md, and are not the authoritative source of work state.

For a new chat, start with the Worklog on the develop branch, then consult the prototype README, ARCHITECTURE.md, VALIDATION.md and relevant source files. If GitHub is unavailable, supply the Worklog as an attachment or paste its contents. Do not infer missing state from conversation memory.
